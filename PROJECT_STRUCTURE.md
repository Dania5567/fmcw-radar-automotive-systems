# Repository structure (figures-only edition)

- `README.md` — comprehensive illustrated project explanation. Every embedded illustration uses a relative file path.
- `assets/figures/defense_###.jpg` — **selected diagram, chart and result crops** from the project defense (number = original slide page). Not the full presentation.
- `assets/figures/*.png` — figures previously extracted from the bachelor's thesis.
- `thesis/Bachelors_Thesis_FYP.pdf` — original bachelor's thesis.
- `docs/` — supporting technical documentation, notes on results and reproducibility.
- `src/matlab/`, `src/rtl/` — placeholders/instructions, **not original executable source code**.
- `hardware/`, `results/` — explanatory material.
- `GITHUB_UPLOAD_INSTRUCTIONS.md` — GitHub upload and image troubleshooting.

The defense presentation PDF, individual full-slide gallery, and gallery document are intentionally omitted.
